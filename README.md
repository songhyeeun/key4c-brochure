# KSMARTECH 모바일 브로슈어

## 바로 열기

`KSMARTECH-mobile-brochure.html`을 브라우저에서 열면 됩니다. 이미지와 스타일이 포함된 단일 HTML이므로 이 파일 하나만 전달해도 열립니다. 외부 폰트·라이브러리·인터넷 연결이 필요하지 않습니다. 웹 공개는 별도 호스팅에 업로드하면 됩니다.

## 내용 및 코드 수정

- `index.html`: 본문, 제목, 연락처, 버튼 링크. 8개 섹션에 주석이 있습니다. 텍스트를 검색해 수정하세요.
- `styles.css`: 색상, 글꼴, 여백, 크기. 맨 위 `:root`에서 공통 색상을 변경합니다.
- `script.js`: 상단 메뉴 열기/닫기, Escape 키 동작.
- `assets/`: 제공받은 원본 이미지. 원본 파일은 변경하지 않았습니다.

수정한 `index.html`은 같은 폴더의 CSS·JS·assets와 함께 즉시 사용할 수 있습니다. 다시 단일 파일로 묶으려면 Node.js에서 `node build-single.mjs`를 실행하세요. 또는 단일 HTML 내부의 본문과 `<style>`을 직접 수정해도 됩니다.

## 구현 범위

8개 시안을 제공된 순서대로 이어 붙인 반응형 웹입니다. 모바일에서 외곽 흰 여백과 모서리 장식을 제거해 가로폭을 채우며, 큰 화면에서는 가운데 정렬됩니다. 시안의 번호 01, 02, 04, 05, 06, 07, 08을 유지했습니다.

제목·본문·카드·버튼·KEY4C 도식·일반 아이콘은 HTML/CSS/SVG로 재구성했습니다. 사진, 지구 및 지도는 원본 이미지의 해당 영역만 CSS로 표시합니다. 건물 간판과 지도 내부의 지역명은 원본 이미지에 포함되어 있어 HTML 텍스트로 편집되지 않습니다. 원본 폰트와 분리된 사진이 없는 상태이므로 서체, 손글씨, 아이콘과 일부 이미지 구도에는 시안과 차이가 있습니다.

메뉴, 섹션 이동, 메일 작성, 전화 연결 및 회사 웹사이트 링크를 연결했습니다. 별도 상세페이지 자료가 없는 버튼은 다음 관련 섹션 또는 연락처로 이동합니다. 문의 버튼은 메일 앱을 열며, 서버로 저장·발송하는 문의 폼은 아닙니다. 언어 표시는 시안대로 EN이며 번역 또는 언어 전환 기능은 포함하지 않았습니다. 전화 링크는 해외에서 사용할 수 있도록 +82 국가번호를 사용합니다.

제공받은 회사 소개·수치·사업 문구는 시안 그대로 옮겼으며 별도로 사실 검증하거나 변경하지 않았습니다.
